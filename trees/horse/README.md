Horse reference and tree
========================

This dataset is provided as an example for how to customize ybyra to other references.

The horse Y chromosome does not exist at chromosomal-level, instead, it is represented by 764 contigs. The reference provided here is based on https://www.ebi.ac.uk/ena/browser/view/GCA_002166905.2 and was adapted by simplifying the contig names to single identifiers.
Some publications also use a reference which has all contigs stitched together by spacers constituted by 500 Ns, see for instance https://zenodo.org/records/7704382#.ZAn-COzMJQP
