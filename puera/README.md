ybyrapûera
==========

This directory contains an additional tool for analyzing and visualizing Y-chromosome data, which for now we call [ybyrapûera](https://en.wiktionary.org/wiki/p%C3%BBer). At this stage, this is experimental, and the code here is meant as a playground for ourselves to try out some new visualizations. This is hence not (yet) a fully usable tool, but feel free to have a look around.
